What it does

Everything needed to ship an installer for a Windows app, without hand-writing installer source or installing a separate toolchain.

MSI and EXE output

Build a standard Windows Installer package, wrap it in a setup.exe, or produce both. The wrapper is generated with the WiX Burn engine and simply carries and installs the MSI inside it, so you end up with one file to share.

Silent install

Produce a package with no user interface at all, for unattended and scripted installs. Options that only apply to an interactive setup are automatically dimmed while it is on, so nothing looks available that will not actually be used.

Apps & features icon

Choose the icon Windows shows for your app in Apps & features. Leave the field empty and the icon of your main executable is reused automatically.

Install path that follows your naming

The default install path is generated from the Manufacturer and Product name fields, so the name only has to be typed once. Type a path of your own, or use Browse, at any time to override it.

Files, shortcuts and registry

  • Collect the files copied into the install folder
  • Add a desktop shortcut, with its own icon
  • Import .reg files: paths are rewritten to the installed location, every other value is preserved exactly as written

Reusable profiles

Each app is saved as its own profile keeping its upgrade code, so a later build upgrades the installed copy instead of installing beside it and leaving two entries in Windows.

License page

Embed your own license text as an .rtf on the installer's license page, so your terms are shown before anything is written to disk.

Clean output

Choose whether to keep the generated source and debug files, so the output folder can hold only the installer you are shipping.

Self-contained

The WiX toolset is bundled. There is nothing to install separately, and no network connection is required to build a package.

Why a packager?

Correct installer source is not something most app authors should have to write, debug or maintain by hand. Zouaouid Tech-Packager keeps the parts that matter — upgrade codes, per-user paths, registry rewriting and silent deployment — behind a profile you fill in once, and rebuild from afterwards.

Getting it

Try it first — the trial has full functionality.

How purchase and activation work

Zouaouid Tech-Packager includes a free trial with full functionality. After the trial, a one-time purchase unlocks permanent access — there are no subscriptions and no recurring fees.

Online: if the device is connected and a previous purchase is recognised, it activates automatically — no key entry required.

Offline: if the server is unavailable or you prefer to, enter the activation code manually. Once activated the app works without a connection.

Direct installer

Prefer the installer over the Store? Download the .msi straight from the releases page — it installs the same application.

The Microsoft Store build is the recommended route: it updates itself and is the listing customers generally expect.

Good to know

Due to the nature of offline, device-bound activation, refunds are not available after license delivery.

Software updates may be provided but are optional and not required to continue using the activated app.
