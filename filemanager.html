Zouaouid File Manager

Key features

An Explorer-style shell with the features power users ask for.

Tabs and multiple windows

Every tab keeps its own folder, history, sort and filter. Pin the tabs you always need, right-click to close, close others or duplicate, and open any folder in a new window with its own tabs.

Adaptive copy engine

Windows copies one file at a time. This engine chooses a strategy from the file count — CopyFileEx for a single file, 8 parallel workers under 1,000 files, 24 concurrent operations under 100,000, and batched streaming above that.

Quick copies stay quiet

The progress window only appears when an operation lasts more than a second. Small copies finish silently with a status-bar message, like Explorer. Larger ones show the current file, strategy, speed, bytes transferred and Cancel.

Real Windows menus

Right-click menus come from the Windows shell itself, so 7-Zip, Git, editors and other shell extensions appear in Explorer's order — drawn with the app's Dark, Grey or Light theme.

Quick access and This PC

Pin any folder or drive to Quick access and drag the rows to reorder them. This PC lists every drive with its Shell icon, volume name, type and free space.

Eight view layouts

Extra large, large, medium and small icons, List, Details, Tiles and Content. Each folder remembers its own layout, and drive rows show a capacity bar in Tiles and Content.

Real Shell thumbnails

The icon layouts show real thumbnails for pictures, video, PDFs and Office documents, and fall back to the file-type icon when there is none. Video thumbnails carry the default player's icon, as in Explorer.

Built for large folders

Virtualized, recycling file lists, native folder enumeration, and Shell icons and thumbnails loaded off the UI thread keep scrolling smooth even with tens of thousands of items.

Renaming and deleting

Slow-click rename, inline rename or a rename window. New items start in rename mode, like Explorer. Delete to the Recycle Bin, or Shift+Delete to delete permanently, with a themed confirmation.

Themes and tray

Dark, Grey and Light themes, Folder Options for hidden and protected files, an auto-hiding top-edge menu, and tray support: run at startup, run minimized, minimize or close to tray.

Why it exists

Windows Explorer is fine until you need more than one folder at a time, thousands of files in one view, or a copy that does not sit at "Calculating..." for minutes. Zouaouid File Manager adds the features power users ask for without changing the way Windows works.

It stays familiar on purpose: the navigation pane, details list and status bar are where you expect them. What changes is what happens when you open a second folder, scroll a huge directory, or move a folder with thousands of small files.

How purchase and activation work

Zouaouid File Manager includes a free trial with full functionality. After the trial, a one-time purchase activates the app permanently on your device — there are no subscriptions and no recurring fees.

Online: if the device is connected and a previous purchase is recognised, the app activates automatically — no key entry required.

Offline: if the server is unavailable or you prefer to, enter your activation key manually. Once activated the app works without a connection.

Installer

The signed .msi can be downloaded directly, or browse the releases page. A Microsoft Store listing will be linked here once it is available.

The app installs per-user and does not require administrator rights. It does not install drivers, services or background components.
